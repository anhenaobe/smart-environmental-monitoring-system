# Interfaz web

Páginas estáticas que sirve el servicio Linux.

- **Bring-up:** formulario de configuración inicial (solo cuando el equipo no está configurado).
- **Inicio:** valores actuales y estado.
- **Historial:** gráfica de las mediciones registradas.
- **Diagnóstico:** CPU, memoria, almacenamiento, red, puertos, UART y estado del STM32.

Sin frameworks pesados: HTML, CSS y JavaScript mínimo que consulta endpoints JSON del servicio.
